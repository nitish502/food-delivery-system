# Food Delivery System

## Project Overview

The Food Delivery System is a Java-based desktop application developed using Java Swing and MySQL. 
It allows users to register, log in, browse restaurants, view food items, manage their cart, and place food orders.

The main objective of this project is to simplify the food ordering process through an easy-to-use graphical user interface.

## Objectives

- To provide a simple and user-friendly food ordering system.
- To allow users to register and log in.
- To display restaurants and available food items.
- To manage cart items and food orders.
- To store and manage application data using MySQL.
- To demonstrate Java OOP concepts and database connectivity.

## Features

- User Registration
- User Login
- Restaurant Browsing
- Food Item Browsing
- Shopping Cart Management
- Order Management
- MySQL Database Connectivity
- Graphical User Interface using Java Swing

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- MySQL Connector/J
- Visual Studio Code
- Git and GitHub
